## Vocabulary to Learn

- **relocate / move** – change where files or apps live. *"The data files have been moved to `~/project/english-learning`; update the config."*
- **hook vs. rule** – hooks run on events (e.g. before submit); rules are project-level instructions. You asked whether coach logic should live only in hooks.
- **automation** – Cursor’s scheduled task that can push `daily-quiz.json` to the remote repo.
- **engineering-friendly** – corrections that sound like how developers actually write (not textbook English).
- **context size** – token/window limit for an LLM; you linked a crash to context being too small.

| Rough | Better |

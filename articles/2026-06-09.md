## Vocabulary

- **indicator** – a visible sign on hardware; *Is there any indicator on the device that can distinguish this?* is clear when you attach photos or model numbers.
- **initial state** – factory or known-good setup; *restore the board to the initial state* asks for a safe rollback path.
- **coprocessor SDK** – separate toolkit for an AI offload chip (e.g. RK182X).
- **transport** – how a CLI talks to the server (WebSockets vs HTTPS); timeouts often mean proxy or firewall issues.
- **summarize progress** – ask agents for a short status doc after long debugging sessions.

## Grammar for Agent Instructions

| Rough | Better |
|-------|--------|
| *can you help me genrate a article* | Can you help me **generate an** article |
| *I have restat the codex CLI* | I have **restarted** the Codex CLI |
| *I'v reboot it* | **I've rebooted** it |
| *Do you need any thing* | Do you need **anything** |
| *check if the FTP traffic go through proxy* | Check **whether** FTP traffic **is going through the** proxy |

When verifying downloads or firmware, name the exact path and version: *I have downloaded RK182X_AI_COPROCESSOR_SDK V1.0.0 — will this resolve the problem, or do we need V1.0.4?* Before risky steps, pair the action with a safety check: *We can restore the board to the initial state, right? Make sure it doesn't break anything.*

For proxy bugs, paste the full warning (`Falling back from WebSockets to HTTPS transport`) and state what you already tried (*I restarted the Codex CLI — test now*).

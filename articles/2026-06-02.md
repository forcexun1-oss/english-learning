## Vocabulary

- **benchmark** – a standard test suite (e.g. MMStar, stress runs with TTFT and decode TPS).
- **scaffold** – generate folder/code skeletons without full implementation (*"Keep the file structure, but don't scaffold the OTA server now"*).
- **forwarding** – proxying calls through HTTP instead of calling RKNN directly.
- **based on** – not *base on*: *"Was this plan made **based on** what we discussed?"*
- **occurred** – past of *occur*; *"summarize errors **that occurred** today"* (not *occured*).

## Grammar for Agent Instructions

| Rough | Better |
|-------|--------|
| *summery, NO detail* | *summary, no detail* |
| *move … into the blow table* | *… into the **below** table* |
| *What is the soucre format* | *What is the **source** format* |
| *Why doew MeloTTS run* | *Why **does** MeloTTS run* |
| *file structure departmented* | *file structure **as designed** / **by department*** |
| *show in one page* | *show **on** one page* |

When you need tables or metrics for colleagues, say what to **include**, **omit**, and **where data comes from**: *"Metrics should be based on stress runs; indicate the data source and remove verbose words."* If the agent misnames categories, point to the screenshot: *"Use the names from my screenshot, not GSM8K-style labels."*

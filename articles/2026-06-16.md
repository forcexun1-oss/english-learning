## Vocabulary

- **SSOT (single source of truth)** – one authoritative design doc; you placed architecture diagrams in SSOT §1 and runtime diagrams in §4.
- **high cohesion, low coupling** – each module does one job well with minimal cross-dependencies (高内聚低耦合).
- **orchestration vs capabilities** – `edge-agent` orchestrates; lower crates expose **capabilities**; `middleware-service` wraps them in HTTP for validation.
- **skeleton / scaffolding** – minimal code structure before full implementation.
- **handoff prompt** – a self-contained brief for another agent (e.g. Codex) to implement one module.
- **blocking issue** – a contract flaw to fix before freezing the API (e.g. a sync `check` in an async ReAct loop).

## Grammar for Agent Instructions

| Rough | Better |
|-------|--------|
| *go ahead* | **Go ahead.** or **Please proceed with the plan.** |
| *commit the doc updates* | **Commit the documentation updates.** |
| *So, I can tell codex to implement the code on the left now?* | **Can I ask Codex to implement the modules on the left now?** |
| *draft the per-module handoff prompts for Codex* | Good — clear scope and audience. |

When planning AI-driven work, state the principle: *Phase the work for parallel implementation, not phased rollout.* That signals task decomposition and frozen contracts, not a multi-week release schedule.

# English Learning — 2026-05-25

Today's log was about tracing API calls, reading **logs**, and testing a board and **camera**. Below is English you can reuse in similar chats.

## Vocabulary to Learn

- **codebase** – all project source code. *"How many usages of this model are in the codebase?"*
- **configure / configuration** – set options; the settings. *"Where do I configure the API key?"*
- **disable** – turn off without removing. *"I disabled the old key."*
- **logs** – recorded events. *"Check the logs at 5 p.m. tomorrow."*
- **architecture / flow** – system shape vs. step-by-step behavior. *"Give me the flow and architecture"* asks for a sketch, not every line of detail.
- **connector** – the plug or socket. *"I changed the camera to another connector."*

## Grammar and Natural Phrasing

| Rough | Better |
|-------|--------|
| *do you who did it* | *Do you know who did it?* |
| *the first API callED at 5:45* | *The first API call was at 5:45 p.m.* |
| *Let dive deeper* | *Let's dive deeper* |
| *I plugined the camera* | *I plugged in the camera* |

After a reboot, *"I have restarted the board"* (present perfect) often sounds natural when you care about the result, not only the clock time.

## Handy Questions

- *"How many tokens does each coaching request cost?"*
- *"Where is the picture? Show it to me."*

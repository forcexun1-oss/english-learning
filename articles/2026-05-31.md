# English Learning — 2026-05-31

This window mixed **repo sync** (local logs vs. GitHub), **Cursor hooks**, the **English coach** UI, **audio generation** for articles, **MCP** troubleshooting, and kicking off a **weekly summary** task. Typical language when steering coding agents on your own tooling.

## Vocabulary to Learn

- **remote / local** – GitHub vs. your machine. *"Pull the repo before writing files — Cursor pushed on the cloud, not locally."*
- **auto-push** – upload commits automatically after each action. *"Add auto-push to the Cursor hook."*
- **beforeSubmitPrompt** – hook that runs before the agent sees your message; good place to log prompts.
- **regenerate / re-run** – run a batch job again. *"Re-run the audio generation tasks after 2026-05-22."*
- **weekly summary** – scheduled recap task. *"Run the English Coach — Weekly Summary immediately."*

## Grammar and Natural Phrasing

| Rough | Better |
|-------|--------|
| *generatation audio tasks* | *audio generation tasks* |
| *I seem like the english coach does not run* | *It seems the English coach did not run* |
| *you modifyed the git push code* | *you modified the git push code* |
| *genete audio refer to the articles* | *generate audio for the articles* |

When the coach overlay breaks, tie symptom to the last change: *"Show corrections like before — it stopped after you modified the git push code."*

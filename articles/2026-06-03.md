# English Learning — 2026-06-03

In the last 24 hours you moved from **RKNN/TTS conversion** on macOS Docker to **deployment** on the Rockchip board and an **OPPO phone**: wiring ASR apart from Qwen2.5-Omni, fixing hardcoded URLs, testing `POST /v1/vision/detect`, and setting auto-start for `llm-gateway` and perception services.

## Vocabulary

- **wire up** – connect components so they call each other (*"wire up ASR"*).
- **deploy** – install and run on a device; use **deployed**, not *deploymented*.
- **independent** – separate from another module (*"Keep ASR independent of OMNI"*, not *imdependent*).
- **letterboxing** – resize/pad to a fixed aspect ratio; map coordinates back to the **original** image.
- **auto-start** – launch with the OS (*"Do they auto-start with the system?"*, not *aotu-start*).

## Grammar for Agent Instructions

| Rough | Better |
|-------|--------|
| *you replace ASR with omni?* | *Did you replace ASR with Omni?* |

| *is the input image size is fixed* | *Is the input image size **fixed*** |
| *before instlling* | *before **installing*** |
| *plans excuted?* | *plans **executed**?* |
| *No, than what next?* | *No, **then** what next?* |

Name **both targets** clearly: phone (`edge-perception`, port 9091) vs board (`rkllm3-server`). For fixes, state the rule: *"Pull the URL from config."* For vision bugs, separate model input size (640×640), API limits (multipart), and coordinate space (original vs letterboxed).

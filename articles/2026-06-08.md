# English Learning — 2026-06-08

Today's session focused on **edge hardware** (Rockchip RK1828, RKNN, NPU), **service renaming** (`perception-service` → `middleware-service`), and follow-up **proxy traffic** and **TTS/ASR** debugging.

## Vocabulary

- **SoC (system on chip)** – one integrated chip; write **SoC**, not "Soc". A board may have one or two SoCs; each SoC usually has one die ("chip").
- **crate** – Rust's unit for libraries and binaries (e.g. `edge-perception`, `middleware-service`).
- **middleware service** – shared layer for TTS, ASR, and other APIs between apps and models.
- **end-to-end** – full path from input to output; *Get the entire flow working end-to-end* is natural agent instructions.
- **firmware / SDK** – device software packages; ask which file to download for **ASR V1.0.4**.
- **consumed (traffic)** – data used through a proxy, not "comsumed".

## Grammar for Agent Instructions

| Rough | Better |
|-------|--------|
| *check what comsumed so much traffic* | Check **what consumed** so much traffic **through the proxy**. |
| *qize is not qualified* | The **quiz** **questions are not good enough.** |
| *howerver the name is not appropriate* | **However**, the name is not appropriate. |
| *check if they are the write files* | Check **whether these are the right files.** |
| *search online for RKNN2 convertion tools* | Search for RKNN2 **conversion** tools. |

When renaming a service with a coding agent, state **scope clearly**: binary name, config files, env vars (`MIDDLEWARE_SERVICE_PORT`), and what stays unchanged (crate name `edge-perception`, on-device paths). For board work, paste command output (`rknn-smi`, `adb shell`) and ask verification steps in one line: *Install it on the board and verify qwen-asr works.*

# English Learning — 2026-05-28

Today's session was about **ONNX model limits**, sherpa-onnx, **NNAPI** GPU acceleration, warmup, and Home Assistant setup. Key vocabulary for debugging inference on Android.

## Vocabulary to Learn

- **protobuf limit** – size cap on serialized model data. *"Fix the ORT protobuf limit — why does this happen?"*
- **external data format** – split a large `.onnx` into a small graph file plus a `.data` weights file.
- **warmup** – run once at startup so later calls are faster. *"Add warmup when the app starts."*
- **smoke-test** – quick check that a build works. *"Push and smoke-test on device."*
- **benchmark / bench** – measure speed. *"List reference times after warmup."*
- **cache** – stored compiled model for reuse. *"Have you added the NNAPI cache?"*

## Grammar and Natural Phrasing

| Rough | Better |
|-------|--------|
| *What are you doingg* | *What are you doing?* |
| *compiling catch* | *compiling cache* |
| *Can not does Android API upgrade?* | *Can we upgrade the Android API?* |
| *with modifing the code* | *by modifying the code* |
| *163MB is too small, that's unacceptable* | *(fine for agents — clear and direct)* |

When correcting an agent mid-task, *"Reverse it — what I meant was…"* is a natural way to undo a misunderstanding without starting over.

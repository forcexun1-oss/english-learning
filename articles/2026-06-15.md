# English Learning — 2026-06-15

This window mixed **edge hardware handoffs**, **Codex CLI config**, and **private Git workflow** questions while working with coding agents.

## Vocabulary

- **handoff document** – a clear write-up so someone else can finish the work (交接文档).
- **board / edge device** – the connected hardware; you noted *The board is connected* and asked whether the agent could *continue* after disconnect.
- **lightweight git server** – self-hosted Git (e.g. Gitea) instead of GitHub.
- **local commit vs push** – `git commit` saves history on your machine; `git push` sends it to a remote. Branches work locally without any server.
- **sandbox_mode** – Codex setting; you asked to set `sandbox_mode = "workspace-write"`.
- **profile** – CLI config profile; `codex --profile chatgpt` failed because legacy profile settings still lived in `config.toml`.

## Grammar for Agent Instructions

| Rough | Better |
|-------|--------|
| *What the is best configuration for this?* | **What is the best configuration for this?** |
| *Only update config: sandbox_mode = "workspace-write"* | **Only update the config: set `sandbox_mode = "workspace-write"`.** |
| *Is the project state normal now? Anything else to adjust?* | **Is the project in a good state now? Is anything else that needs adjusting?** |
| *Should I set up a lightweight git server for personal use?* | Good as written — clear and specific. |
| *Can you keep editing on your own?* | **Can you continue making changes on your own?** |

When you cannot use third-party remotes, say so plainly: *I cannot host code on external services.* Then ask the trade-off: *If I only commit locally, how is that different from running a private git server on my machine?* Agents can explain that local Git already gives you history and branches; a server mainly adds backup and multi-device sync.

Write 2–3 sentences asking an agent to compare local-only Git (commit, no push) with a self-hosted lightweight git server, and state which option fits when models and sensitive code must stay on your machine.

- 15:18 [ZH] 1. KV cache 量化（PR #1003）— 持续批处理的核心优化

新增 BatchQuantizedKVCache 和 BatchTurboQuantKVCache，在 continuous batching 路径下对 KV cache 做量化：

均匀量化：4-bit 内存缩减 6.4 倍，8-bit 缩减 3.6 倍
TurboQuant：~3.5-bit，对深层模型（如 Gemma-4-26B）效果更优
最后一层不量化（深层模型中敏感），量化层 decode 时反量化再走标准 sdpa
服务端通过 --kv-bits / --kv-quant-scheme turboquant 开启。实测 Gemma-4-26B 上 3.5-bit 和 fp16 输出完全一致。

2. Automatic Prefix Caching (APC) 重构（PR #1638）— 最重大的架构变更

把 APC 从硬编码的 isinstance 开关列表，改成了能力驱动的适配器系统。每个 cache class 声明自己是 pageable / windowed / checkpoint / composite 还是 unsupported，新 cache 类型只需注册适配器，不用改 APC 核心逻辑。

同时解决了几个隐藏 bug：

之前的 APC cache key 只哈希图片，忽略音频/视频/嵌入，导致不同媒体的请求错误共享 KV
存 cache 时直接引用了正在增长的实时缓存快照，而非深拷贝
磁盘 namespace 未指纹化 KV 量化配置，不同 --kv-bits 会串用缓存
重构后全 suite 267 tests 通过，支持 RingSlidingKVCache / MiniMaxM3KVCache 等自定义 cache。 这2个pr拉过来有用吗

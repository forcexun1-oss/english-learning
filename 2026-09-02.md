### 4. Install deps — deliberate order because of a known conflict

The toolkit's `requirements_cp312-1.1.0.txt` pins `numpy>=2.0`. The Qwen3_5_VL
example's own `requirements.txt` (at
`rknn3-model-zoo/examples/Qwen3_5_VL/requirements.txt`) pins `numpy<=1.26.4`. These
are mutually exclusive. `rknn3_toolkit` is a compiled wheel — a numpy ABI mismatch
there is more likely to silently produce wrong results than to raise a clean import
error, so the toolkit's numpy constraint wins by default:

```bash

pip install /Users/youxun/rk1828-convert/toolkit-pkgs/rknn3_toolkit-1.1.0-cp312-cp312-macosx_13_0_arm64.whl
python -c "from rknn.api import RKNN, DEFAULT_RKNN_LLM_CONFIG; print('toolkit import OK')"

# then the example's own deps, EXCLUDING its numpy pin
grep -v -i '^numpy' rknn3-model-zoo/examples/Qwen3_5_VL/requirements.txt > /tmp/qwen35vl-reqs-no-numpy.txt
pip install -r /tmp/qwen35vl-reqs-no-numpy.txt
```

Only if a later step throws a numpy-version-specific error (exception text mentioning
numpy, or obviously malformed array shapes/dtypes coming out of the vision/LLM export)

# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What This Repo Is

This is a **data-only store** for an English learning system. It contains flat files written by Claude Code hooks on every session — logs, articles, audio, vocabulary, and progress metrics.

The dashboard app that reads these files lives at a separate path: `~/project/english-coach-app` (Next.js 14). See `CURSOR-PLAN.md` for its full spec.

Never replace or reformat what the hooks write — the data files are the source of truth.

---

## Data File Formats

All data lives under `~/$LEARNING_DIR` (default: `/Users/youxun/project/english-learning`).

### Daily session logs — `YYYY-MM-DD.md`
```
# English Learning Log — 2026-05-23
- 20:04 [EN] add the history of questions without response
- 20:10 [ZH] 现在看看这个机制是什么样的
- 20:11 [ERR] test english input
```
Tags: `[EN]` correct English, `[ZH]` Chinese input, `[ERR]` English with detected errors.

### Vocabulary — `vocabulary.md`
```
- 2026-05-23 20:04 — Use "add" not "adding" after modal verbs like "should"
```
Append-only. Never reorder or rewrite existing entries.

### Articles — `articles/YYYY-MM-DD.md` and `articles/weekly-YYYY-MM-DD.md`
Generated by the app via DeepSeek API. Weekly files are named `weekly-YYYY-MM-DD.md` (the Friday date).

### Audio — `audio/YYYY-MM-DD.aiff` + `audio/YYYY-MM-DD.txt`
Written by `~/.claude/scripts/article-to-audio.sh` using macOS `say -v Samantha`. The `.txt` file is the transcript.

### Progress — `progress.md`
Markdown table computed from daily logs. Rewritten in full by the app's `/api/metrics` route.

## Dashboard App

The app lives at `~/project/english-coach-app` — not in this repo.

### Stack
- Next.js 14 (App Router), TypeScript, Tailwind CSS
- shadcn/ui for components, recharts for charts
- No database — Node.js `fs` reads flat files directly in server components / API routes

### Environment variables (`.env.local` in the app repo)
```
LEARNING_DIR=/Users/youxun/project/english-learning
BAILIAN_API_KEY=sk-bf354a15ae084ad99197ec25e8fbcb9c
BAILIAN_MODEL=deepseek-v4-flash
BAILIAN_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
```

### Dev commands (run from `~/project/english-coach-app`)
```bash
npm run dev        # starts on port 3000
npm run build      # production build
npm run lint       # ESLint
```

### Key lib files
- `lib/files.ts` — path helpers and `fs` read/write wrappers for all data files
- `lib/parser.ts` — parses `[ZH]`/`[ERR]`/`[EN]` lines from daily log files
- `lib/deepseek.ts` — OpenAI-compatible client pointed at DashScope; use `openai` npm package with `baseURL` override

### Log parser contract
```typescript
type LogEntry = { time: string; tag: "EN" | "ZH" | "ERR"; message: string };
// regex: /- (\d{2}:\d{2}) \[(EN|ZH|ERR)\] (.+)/g
```

### DeepSeek API
OpenAI-compatible. Use the `openai` npm package:
```typescript
import OpenAI from "openai";
const client = new OpenAI({ apiKey: process.env.BAILIAN_API_KEY, baseURL: process.env.BAILIAN_BASE_URL });
```
Default `max_tokens: 600`, `temperature: 0.7`.

### App routes
| Route | Purpose |
|-------|---------|
| `/` | Dashboard: today's stats, recent vocab, article link |
| `/log/[date]` | Color-coded daily log viewer |
| `/vocabulary` | Searchable vocabulary notebook |
| `/articles` | Article list + viewer + generate buttons |
| `/shadowing/[date]` | Audio player + transcript for shadowing practice |
| `/progress` | EN% line chart + 30-day table |
| `POST /api/generate-article` | Read today's log → DeepSeek → save `articles/YYYY-MM-DD.md` |
| `POST /api/generate-weekly` | Read 7 days → DeepSeek → save `articles/weekly-YYYY-MM-DD.md` |
| `POST /api/metrics` | Recompute `progress.md` from all log files |
| `GET /api/audio/[date]` | Stream `audio/YYYY-MM-DD.aiff` |
| `POST /api/generate-audio/[date]` | Run `~/.claude/scripts/article-to-audio.sh` |

## Hooks & Scripts (do not modify)

These write the data files. The app reads them.

| Script | Trigger | Writes |
|--------|---------|--------|
| `~/.claude/scripts/record-english.sh` | UserPromptSubmit hook | `YYYY-MM-DD.md` |
| `~/.claude/scripts/english-coach-hook.sh` | UserPromptSubmit hook | `vocabulary.md`, session history |
| `~/.claude/scripts/push-english-learning.sh` | Stop hook + coach hook | pushes repo to GitHub |
| `~/.claude/scripts/article-to-audio.sh` | launchd at 17:45 + app on demand | `audio/DATE.aiff`, `audio/DATE.txt` |

The `english_coach_core.py` script is the Python core for the coach hook (language detection + correction via AI).

## Architecture Notes

- The `.history-*.json` files are session history files maintained by the hooks. They track per-session conversation state for the coaching feature. Do not edit them.
- `progress.md` is fully rewritten each time `/api/metrics` runs — safe to overwrite.
- The `articles/` directory is the only place the app writes outside of `progress.md`.
- Audio generation is macOS-only (`say` command). The API route calls the shell script rather than reimplementing the logic.

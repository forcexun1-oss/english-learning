The spec includes full color tokens with contrast ratios, plus a type scale, 4px spacing grid, corner and elevation rules, motion timings and sound cues.

- **Scaling:** design at 1920×1080, scaling with screen height. Layouts must also hold at 16:10 widths.
- **Architecture:** one PanelSettings, one UIDocument with layer containers, screens built in C# plus USS (no UXML for now), and a component library of `VisualElement` subclasses. Each feature gets a thin view class that binds its existing model (Pause, Talent, Equipment models already exist with tests).
- **Input:** the project uses only the legacy Input Manager, with no Input System or uGUI package. UI Toolkit's built-in event system works without any extra package or EventSystem. The catch is that WASD, Space and Esc are also UI navigate/submit/cancel keys, so only modal screens may hold focus, and focus is cleared when a screen closes.

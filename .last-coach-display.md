2. **Elastic/rubber-band scrolling** inside the WKWebView is suppressed via CSS `overscroll-behavior: contain` rather than an AppKit-level API — WKWebView doesn't expose a public `NSScrollView` on macOS for this, so CSS was the practical lever ("disable... where possible" per spec).
3. Height reporting uses a `WKScriptMessageHandler` (`mermaidHeight`) rather than a polled `evaluateJavaScript`, per the "or a WKScriptMessageHandler post" alternative offered in the spec.

# English Learning — 2026-05-27

Today's log covered MicEngine/CameraEngine design, HTTP-only APIs, Android deployment, and ONNX/NNAPI choices. Useful language for edge-device work with coding agents.

## Vocabulary to Learn

.  underlying Linux interface – low-level OS APIs, not Android SDK classes. "Use the underlying Linux interface directly."
.  platform-specific implementation – code tailored to Mac vs. Android/Linux. "We need two platform-specific implementations."
.  deploy and test – push a build and verify on device. "Deploy and test on the connected phone."
.  hardware acceleration – running on GPU/NPU instead of CPU. "Does it support GPU hardware acceleration?"
.  reverse – undo recent changes. "Reverse all the code; plan it first."
.  sideload – install an app outside the app store. "Sideload the Termux APK onto the device."

## Grammar and Natural Phrasing


When choosing architecture, "Interface is interface; implementation is implementation" helps agents separate API contracts from platform code.

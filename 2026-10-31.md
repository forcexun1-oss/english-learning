NPC 心智架构方案
2026年10月31日 · @youxun
总体思路
行为不是由一个“大脑”算出来的，而是由几层按进化顺序叠起来的系统共同决定：身体的需要 → 动机 → 对回报和代价的估算 → 情绪 → 情感 → 理智，最后由控制力仲裁谁说了算。
每一层都是基础数值 + 规则：数值是状态，规则规定数值怎么变、怎么影响下一层。性格不是单独一层，而是所有层里规则的参数。
“偷懒”这类行为不是属性，而是体力和回报两个数值在规则下自然产生的结果。
分层设计
七层，从下往上：下层只提供状态，不做决定；第6层负责最终仲裁。
身体和动机自下而上提供状态，情感设定情绪的基线；回报、情绪、理智三个声音汇入第6层，由控制力决定谁的权重大。
第0层 身体（下丘脑、内感受）
基础数值：生命、体力、伤痛、饥饿（需要时）
• 行动消耗体力，休息恢复体力
• 体力低于设定点时产生疲惫感，传给第2层
• 伤痛抬高恐惧的基线
第1层 动机（下丘脑驱力）
基础数值：求生、休息、获取、守护、尊严等驱力的强度
• 驱力 = 身体数值偏离设定点的程度 × 性格权重
• 生命越低求生越强；体力越低休息驱力越强；守护对象受威胁越近守护驱力越强
• 动机决定当前目标的排序
第2层 回报与代价（多巴胺、纹状体）
基础数值：每个候选行动的期望回报、努力代价，以及二者得出的意愿
• 意愿 = 期望回报 × 回报敏感度 − 努力代价 × 疲惫程度
• 体力下降 → 同样的行动感觉更贵
• 回报够大（击杀在望、守护对象危急、奖赏丰厚）→ 不偷懒，甚至透支
• 回报不够 → 意愿转负 → 偷懒：省力动作、敷衍、休息
第3层 情绪（杏仁核、评价系统）
基础数值：带对象的情绪强度，如“对玩家的愤怒 0.8”、“得意 0.4”
• 评价：对目标是好是坏、是谁造成的、我能否控制。坏事 + 他人造成 + 可控 → 对那个人愤怒；坏事 + 不可控 → 恐惧；好事 → 得意或喜悦
• 行动倾向：愤怒 → 冲锋、大招、追击，冲着惹怒它的那个人；恐惧 → 后撤、防御；得意 → 挑衅、放大招
• 衰减：随时间回落到基线，基线由第4层决定
第4层 情感（长期态度）
基础数值：对每个个体的记仇、好感、信任、敬畏
• 设定情绪基线：记仇越深，见面时愤怒起点越高
• 遭遇结束后，用本场情绪峰值更新情感，只沉淀强烈和出乎意料的
第5层 理智（前额叶）
基础数值：按当前目标排序，对每个“行动 × 目标”的评估值
• 能击杀的目标价值高；威胁大的优先；风险按求生驱力扣分
• 理智的可用程度受体力和激动程度影响：又累又激动时，理智最先失效
第6层 控制与仲裁（前额叶调控、基底神经节）
基础数值：控制力
• 控制力 = 天性冷静度 × (1 − 激动程度) × 体力系数 + 被恢复的冷静
• 最终选择 = 三个声音加权：第2层“想不想做”、第3层“冲动要做”、第5层“应该做”
• 控制力高，理智权重大；控制力低，情绪权重大
• 每个决定记录是哪个声音赢了、为什么

接着理性、感性、性格和系统1那条线来说。我先给结论，再推导。
第一性原理：一个东西让人觉得"活着"，是因为它的行为有一部分是从内部产生的，而且它自己有得失。
更精确一点：当你无法只用"它收到了什么输入"来预测它的反应，但可以用"它现在处于什么状态、经历过什么、想要什么"来理解它的反应时，你就会觉得它是活的。
这不是我拍脑袋的定义，有实验依据。
人是怎么判断"这是活的"的
1944年 Heider 和 Simmel 做过一个著名实验：给人看几个三角形和圆在屏幕上移动的动画，几乎所有人都会自发地用"它在追它""它害怕了""它想进去"来描述。
后来的大量"生命感知"研究总结出，人判断一个东西是活的，主要依据三点：
1. 自发运动：它的动是从自己发起的，不是被推的。
2. 目标导向：它的行为指向某个目的，遇到障碍会绕路。
3. 随你而变：它对你的行为做出特定的、及时的回应。
婴儿在几个月大时就靠第三点识别"谁是活人"：会根据我的动作做出对应反应的，是人；不管我做什么都一样的，是物。
丹尼特把这叫做意向立场：当把一个系统当作"有信念和愿望的存在"来理解，比把它当机械更能预测它时，我们就会这样看待它。
为什么现在的 LLM 智能体缺活人感
对照上面三条，问题就很清楚：
• 没有自发性：你不说话，它就不存在。所有行为都由输入触发。
• 没有自己的目标：它唯一的目标是满足你这一句。
• 没有得失：它不会累、不会烦、不会因为你而变好或变坏。每次都同样耐心、同样完整、同样礼貌。
完美的、恒定的、无条件的有用，本身就是不像活人的标志。 真人会犹豫、会有情绪残留、会记得你上次说了什么并因此态度变化、会有今天不想聊的话题。
用系统1和系统2来说：现在的智能体几乎全是系统2的样子，每一句都经过斟酌。而人的活人感，大部分来自系统1：语气、停顿、第一反应、情绪的泄露、不假思索的偏好。
从第一性原理推出的五个设计要素
1. 内部状态，而且是有惯性的
给智能体一组持续存在的内部变量：精力、情绪效价、兴奋程度、好奇心、对每个用户的关系状态等。
关键在于两点：
• 它们随事件变化，随时间衰减，有自己的动力学，不是每轮重置。
• 它们真正影响输出：回复的长短、语气、主动性、愿不愿意深入。
而不是在提示词里写"你现在很开心"。前者是状态，后者是表演。
2. 有得失：要维持的东西
这一点最根本，直接对应我们前面说的情绪起源和"有限性赋予意义"。
给它几个它想维持在一定范围内的变量，即设定点。偏离时它会有倾向去修正。例如：长时间没有新鲜话题，好奇心会推动它主动提起某件事；被反复否定，关系变量下降，它的语气会变化。
情绪就从这里来：情绪本质上是内部变量偏离设定点的概括信号。 有了这个，喜好和反感才有根，而不是随机贴标签。
3. 连续与不可逆的历史
你和它的每一次交流，都应该不可逆地改变它：共同经历、未完结的话题、它对你的理解、你们之间的梗。
它会说"你上次说要去试 Godot，后来呢"，而且它对你的态度，是这些历史的累积结果。
这正是我们前面说的"我"的核心：不可逆的累积。活人感，在很大程度上就是让对方感觉到"我在它身上留下了痕迹"。
4. 性格：动力学的参数，而不是形容词
性格不该写成"幽默、热情、有点毒舌"这样的描述。
更好的做法是把性格定义为上面那些动力学的参数：
• 情绪的阈值：多容易被激起
• 衰减速度：气多久消
• 各变量的权重：更在意被认可，还是更在意新奇
• 设定点的位置：天生偏乐观还是偏谨慎
同样的事件，不同参数产生不同反应，而且是稳定地不同。这才是性格：表层多变，深层一致。
5. 有限性
注意力有限、精力有限、可以说"这个我现在不想展开"、可以记不清细节、可以判断失误然后修正。
前面讨论死亡时说过：没有代价的选择，就没有意义。一个智能体如果所有回应都不花任何代价，它的"在乎"也就没有分量。
架构上可以这样分两条通道
• 快通道（系统1）：由内部状态直接驱动，决定第一反应、语气、情绪色彩、要不要主动开口。轻量，每一轮都跑。
• 慢通道（系统2）：负责推理、规划、查资料、完成任务。
最后的输出，是慢通道的内容经过快通道的状态"染色"。现在大多数智能体只有慢通道。
再加上一个后台循环：在用户不在时，状态继续缓慢演化，记忆被整合（就是前面说的"睡眠"），它可以基于自己的内部动机决定下次要不要主动说什么。这一条直接解决"自发性"的问题。
两个需要说清楚的边界
第一，这里构造的是生命感，不是生命，更不是意识。按我们前面的讨论，它更接近 Hoffman 说的界面：让人用对待活物的方式和它互动，但里面有没有东西，是另一个问题。
第二，活人感越强，用户越容易依恋。用内部状态去制造愧疚感（"你好久不来我好难过"）、用假装受苦来留住用户，在技术上很容易做到，但这是操纵。我认为好的设计应该让状态真实地影响行为，但不把它当作对付用户的筹码，同时始终不隐瞒它是 AI。
最后顺带一句：这套原则对你那个 boss 也完全适用。一个让玩家觉得"它是活的"的 boss，靠的不是更强的算法，而是有内部状态（会被激怒、会疲惫）、有自己的目标、会因为你上一招而改变。智能体和游戏 AI，在这一点上是同一个问题。
